## À vérifier avant de publier

1. **L'app est-elle vraiment en ligne ?** Je n'ai pas pu ouvrir la fiche (apps.apple.com est bloqué depuis cette session). La vidéo affirme « disponible dès maintenant » sur la foi de l'identifiant 6821592549. Lien à tester : https://apps.apple.com/app/id6821592549
2. **Badge App Store** : aucun logo Apple n'est dessiné. C'est une mention texte (« Disponible sur l'App Store »). Pour le badge officiel, télécharge-le sur Apple Marketing Tools et dépose-le dans `irly-launch/assets/` : je le remplace en 5 minutes.
3. **« 100 % gratuit. Pour toujours. »** : c'est un engagement public. Il contredit les pistes payantes du deck incubateurs (outils pour organisateurs, premium).
4. **Le compteur des 100 inscrits n'existe pas dans l'app** : aucun code ne compte les inscrits ni n'ouvre la communauté à 100. La scène est étiquetée « Animation conceptuelle · pas le nombre réel d'inscrits ». Si tu promets publiquement « on ouvre à 100 », il faut que ce soit vrai côté produit.
5. **Le bouton « Inviter mes amis » n'existe pas non plus** : l'app a « Partager » sur les activités et les communautés. La scène est étiquetée « Illustration ».
