# Dépôt LinkFoot

Ce dépôt contient `linkfoot-engine` : le moteur de match et les règles manager,
sortis de l'écran Mon Club pour tourner dans l'app et être sauvegardés.

```bash
npm test             # simule 200 matchs et contrôle l'équilibrage
npm run demo         # http://localhost:8787
npm run build        # régénère dist/linkfoot.js
```

Aucune dépendance à installer. Voir `README.md` pour React, React Native et Express.
