Brancher ton backend

Remplace LocalStore par HttpStore et la sauvegarde part sur ton serveur :

const store = new LinkFoot.HttpStore({
  url: 'https://api.linkfoot.app/clubs/' + userId + '/save',
  headers: { Authorization: 'Bearer ' + token }
});
const mgr = new LinkFoot.SaveManager(club, store, { delay: 1500 }).start();
await mgr.load();
